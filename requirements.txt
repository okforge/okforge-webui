# okforge-webui venv: the engine + everything the webui and MCP server
# import on top of it. All version pins.
#
# The engine — auto-published to PyPI from
# https://github.com/okforge/okforge on every release tag.
#
# 0.10.0 emits Open Knowledge Format v0.2: wiki frontmatter carries
# `sources` as {id, resource} mappings and `generated: {by, at}` in place
# of the retired `timestamp`. Bundles written by earlier versions stay
# readable, so this is safe to deploy over an existing KB root; pages a
# new ingest touches convert, untouched pages stay v0.1. `okforge
# okf-migrate` converts a whole bundle if you want one uniform.
#
# 0.10.1 makes `add` exit non-zero when compilation fails. Required by
# this webui: jobs._run_add raises on a non-zero exit, so on 0.10.0 and
# earlier a wholly failed ingest was marked done.
